<h2>About Field Test</h2>
<p>Field Test is an error log for people who run sessions with a robot. Each common error has its own tile on the board. Double-tap the tile and the error goes into the day's log with the local time. At the end of the day, share the log as plain text. It is for iPhone and iPad, costs 6.99 USD once, and is listed in the App Store as Data Not Collected. The source code is public under the GNU General Public License, version 3 or later.</p>
