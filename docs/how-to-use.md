<h1>How to use Field Test</h1>
<p class="icl-lead">Three steps cover a normal day. The Guide has the rest.</p>
</div></section>

<section class="icl-section"><div class="icl-wrap">
<div class="ft-row">
<div>
<h2>Step 1: Set up your board</h2>
<p>Open the app. The first screen asks how you want to start.</p>
<ul>
<li><strong>Someone gave you a setup file?</strong> Tap Import a setup file. The app shows what is in it and asks you to confirm before it changes anything.</li>
<li><strong>On your own?</strong> Tap Set up by hand. Enter your name as tester and a unit prefix such as UNIT. Then tap Add error types and make a tile for each error you log.</li>
</ul>
<p><a href="../guide/setup/#your-board">Setting up the board</a> in the Guide.</p>
</div>
<figure class="icl-device"><img src="../guide/img/log-empty-board.png" width="402" height="874" loading="lazy" alt="The Log screen before any error type exists: a card that says Your board is empty and has an Add error types button."></figure>
</div>
</div></section>

<section class="icl-section icl-section--tint"><div class="icl-wrap">
<div class="ft-row ft-row--flip">
<div>
<h2>Step 2: Log through the day</h2>
<ol>
<li>Fill in Today's details: unit number, place and software version. You can log first and fill it in later.</li>
<li><strong>Double-tap</strong> a tile when the error happens. The time is taken from your phone. A message says what was logged, and the count on the tile goes up.</li>
<li>Tapped the wrong one? Tap <strong>Undo</strong> within five seconds.</li>
<li>Want to say more? <strong>Hold</strong> the tile. If you typed a note first, it goes with the error. If not, the entry opens so you can type one.</li>
<li>Not on the board? Tap <strong>Other</strong>, then search or add a new error type.</li>
</ol>
<p><a href="../guide/logging/">A day of logging</a> in the Guide.</p>
</div>
<figure class="icl-device"><img src="../guide/img/log-board.png" width="402" height="874" loading="lazy" alt="The Log screen with a board of tiles and the message Stopped Responding logged at 10:20 with an Undo button."></figure>
</div>
</div></section>

<section class="icl-section"><div class="icl-wrap">
<div class="ft-row">
<div>
<h2>Step 3: Share the log</h2>
<p>At the end of the day, open <strong>Review</strong>. It is today's log in the same words you will send. Tap an entry to fix it. Tap <strong>Share log</strong> and choose where it goes: a chat app, Mail, Files or the clipboard.</p>
<pre class="ft-log">10:20 T| Stopped Responding
11:02 T| Incorrect Action – asked for task 2</pre>
<p>Only Share log marks a log as shared. Copying does not. The next morning the app offers to start a new log. Yesterday's stays in History.</p>
<p><a href="../guide/sharing/">Sharing and the next day</a> and <a href="../guide/history/">History</a> in the Guide.</p>
</div>
