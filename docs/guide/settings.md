# Settings

What each setting does, its default, and where to read more. The list is by purpose and not by where a row sits on the
screen, because the screen changes more often than the meaning.

## Who you are

| Setting | What it does | Default |
|---|---|---|
| **Tester** | Your name, at the top of every log you share | Asked on first launch |
| **Unit prefix** | The letters before a unit's number, for example `UNIT`. You type the number in Today's details | Asked on first launch |
| **Number suffixes** | The words offered after a unit number, such as `prod` and `dev`. **None** is always the first choice | `prod` and `dev` |

[Today's details](todays-details.md) shows how the three come together as `UNIT-27-prod`.

## What you log

| Setting | What it does | More |
|---|---|---|
| **Error types** | The whole list of what you can log. The first 11 are the board; the rest are under **Other…** | [Setting up the board](setup.md#error-types) |
| **Your board** | Which type is on which tile | [Setting up the board](setup.md#your-board) |
| **Locations** | The places Today's details offers | [Setting up the board](setup.md#locations-and-number-suffixes) |
| **Note templates** | The chips above the note field. Each asks a question and writes the line for you | [Setting up the board](setup.md#note-templates) |

A type you **retire** leaves the board and **Other…**, and stays on the entries already logged.

## What the shared log says

| Setting | What it does | Default |
|---|---|---|
| **Include a totals line** | Ends a shared log with the count of each error type | Off |
| **Time format** | 24-hour or 12-hour, with or without seconds. It applies to every log, earlier days too | 24-hour, no seconds |
| **Error prefix** | The marker before each error line. Change it only if the tool that reads your log expects another. **Reset to T\|** puts it back | `T\|` |
| **Names in shared logs** | How a person's name is written when a log leaves the phone: Initials, Full name or Someone | Initials |

[The shared log format](shared-log-format.md) shows what each of these changes in the text.

## The second board

| Setting | What it does | Default |
|---|---|---|
| **Second board: Observations** | Shows the Observations board and its tab | Off |
| **Observation types** | The tiles of that board and the line each writes | None: the app has no types of its own |
| **People** | The list of names an observation can use | Empty |

[Observations](observations.md) is the overview.

## Setup files

**Import or export** moves your setup between phones, or restores it. Importing replaces your setup and touches no logs.
[Rolling out to a team](rolling-out.md) covers sending one to other people.

## Help and about

- **Quick help** opens short answers that work without a connection. Each topic ends with a link to this guide.
- **User guide**, **Support** and **Privacy** open pages of this site in your browser. The app itself makes no connection:
  the browser does.
- **About Field Test** lists the version of the app and, under **This build**, the commit. Give both to Support when you
  report a problem. It also lists the open-source components and their licences, and links to the source code.

## What is not a setting

- There is no account, and nothing to sign in to.
- There is no setting for syncing, backup or sending data anywhere, because the app does none of those.
- The time of an entry comes from the phone's clock. You can change an entry's time in [Review](sharing.md#review).
