# User guide

Field Test is for logging what goes wrong during a session, as it happens, and sharing the log at the end of the day. This
guide covers using the app and, for people who prepare setups or read the shared text with a tool, the details.

## A day with Field Test

1. **Set up once.** Add the errors you log as tiles, or import a setup file. ([Setting up the board](setup.md))
2. **Fill in Today's details.** Unit, place and software version. You can log first and fill it in later.
   ([Today's details](todays-details.md))
3. **Double-tap as it happens.** The tile logs the error with the time. Hold it to add a note. Undo is there for five
   seconds. ([A day of logging](logging.md))
4. **Share the log.** Review the day, then send it as plain text. ([Sharing and the next day](sharing.md))
