CS Bingo Board is a one-tap error log for people who run sessions with a robot.

Each common error has its own tile on the board. Tap the tile and the error goes into the day's log with the local time. Notes, templated notes and changes to the day's header, such as a new software version, go into the same journal, in time order.

At the end of the day, share the log as plain text: to a chat app, email, a file or the clipboard.

ON THE BOARD
• Up to 11 error tiles plus Other, each with its own colour and a running count
• Undo for a mis-tap
• Free-text notes, and note templates for the things you write every day

THE DAY'S LOG
• A header with the facilitator, date, unit, location and software version
• Changes to the header during the day are logged with their time
• Review, edit, copy or delete any entry
• Earlier days kept in History

SET UP YOUR WAY
• Set up the board by hand, or import a setup file shared from a computer or another device
• Light and dark appearance, and larger text
• On a tablet, the board and the log side by side in landscape

PRIVATE BY DESIGN
CS Bingo Board has no account, no internet access, no analytics and no advertising. Your log stays on your device and leaves it only when you share it.
