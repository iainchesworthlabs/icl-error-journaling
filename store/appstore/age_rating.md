# App Store age rating: drafted answers

The answers for App Store Connect, App Information, Age Rating. They follow Apple's 2025 questionnaire, as remembered.
Task 11.0 checks each question against App Store Connect before 11.8 enters them. See
[`docs/plan/stage-11.md`](../../docs/plan/stage-11.md#age-rating).

## Features and capabilities

| Question | Answer | Reason |
|---|---|---|
| Parental controls | No | |
| Age assurance | No | |
| Unrestricted web access | No | No web view and no browser in the app |
| User-generated content shared with other users | No | Notes stay on the device. Sharing goes through the system share sheet to apps the user picks |
| Messaging and chat | No | |
| Advertising | No | |

## Content (frequency)

Every item is **None**:

- Cartoon or fantasy violence; realistic violence; prolonged graphic or sadistic violence; guns or other weapons
- Profanity or crude humour; mature or suggestive themes; horror or fear themes
- Sexual content or nudity; graphic sexual content and nudity
- Alcohol, tobacco or drug use or references
- Medical or treatment information; health or wellness topics
- Simulated gambling; gambling; contests. The "bingo board" is a grid of tiles. Nothing is won, wagered or scored
