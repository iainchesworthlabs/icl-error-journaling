**The unit and the versions are easier to fill in.** On Today's details the Environment row is now called Number suffix and says where it goes ("Added after the number, like UNIT-27-prod"); Settings calls its list Number suffixes. The software version field is for the robot and shows a fixed v, so you type the numbers only (a typed v is not doubled), and every version prints as v1.2.3 in the log, in the change lines and in the shared text. A new Other versions row holds further versions with a name, such as the Influencer phone app: Add a version, name it, type its numbers, Done. They are printed under the Software Version line, for example "Influencer Version: v4.5.0". Logs from earlier versions open as before, with the robot version they had. An older build cannot read a log or a backup that has other versions. Not yet run on a device.
