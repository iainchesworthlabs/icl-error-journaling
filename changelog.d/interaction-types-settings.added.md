**You can set up the Interactions board in the app.** With the second board on, Settings shows **Interaction types** and **People** under the switch. The empty Interactions board's **Add interaction types** now opens the editor straight away, and turning the board on with nothing set up opens it too. Add, rename, reorder and retire types, and give each a line such as “Spoke with [person]”: a type with [person] asks who after you log it, one with [answer] asks a question, and one with neither logs at once. Not yet run on a device.
