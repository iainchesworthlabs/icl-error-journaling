**The list of people can remember a change of location.** The people journal has a new record, `set_person_location`, that moves a person to another location or to none, so a person no longer has to be added again to change it. The screen for it follows. A journal that never changed a location is written exactly as before; one that did is not readable by an older build, which sets a copy aside and keeps the people it could read. Not yet run on a device.
