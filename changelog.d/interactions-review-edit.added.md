**An interaction shows in Review in the same words as the export, and can be fixed afterwards.** With the second board on, an interaction line reads like `Spoke with Alex Sample`, with the full name on the screen; an interaction with no person shows "(person not set)". Tap it to open Edit entry and change the type, the people, the answer, the time or the note, then Save (Cancel keeps it as it was); this is also how to add the people to an entry logged with Skip. Swipe, Copy, Delete and Undo work as for errors. Not yet run on a device.
