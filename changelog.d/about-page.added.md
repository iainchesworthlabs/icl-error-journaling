**There is an About page.** The last row of Settings, “About CS Bingo Board”, opens it. It shows the version, the build number, the commit, the branch or tag when there is one, the date of the commit (UTC), the platform, the Qt version and the storage; the licence of the app (GPL-3.0-or-later) with a row that opens the full text; the address of the source code, which opens in the browser; and the open-source components the app is built with, each with its version, its licence and a page with the licence text. The list is made by the build from what the app really links, and the build stops when a library has no licence entry. Five quick taps on the Version row show the launch and tap timings, as they did on the version line at the foot of Settings, which is now plain text. Not yet run on a device.
