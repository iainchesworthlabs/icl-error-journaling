**The note template editor uses plain words.** A template now has a Name (the chip on the Log screen), a Question to ask (what you are asked when you tap the chip) and a Line in the log (what gets written), with one sentence at the top saying what a template is for. You no longer type curly brackets: an Insert answer button puts the answer in the line at the cursor, shown as [answer], and an Example under the fields shows the log line, such as "In the log: 10:30 (Free Text) Played Morning Medley". A new template starts with its question and line made from its name. The refusal messages and the setup-file import messages use the same words, and the list says "Asks" and "Logs". Setup files are unchanged. Not yet run on a device.
