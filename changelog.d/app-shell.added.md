**CS Bingo Board now has its screens.** The app opens on the Log board, with tabs for Review, History and Settings. You can set up by hand or import a setup file on first launch, fill in today's details, tap the board to log errors, add notes, undo, review and edit the log, share it, start a new day, look at past logs in History, and change the setup in Settings, including its error types, locations, note templates, import and export. Written for the iPhone but only run off-screen so far; the import and export file picker is not connected on the phone yet. Not yet run on a device.
