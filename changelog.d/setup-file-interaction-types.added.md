**Setup file: interaction types and the Interactions board switch.** A setup file can now carry `interaction_types` (a name, a board position from 1 to 11 or none, and an optional line such as `Spoke with {person}` or `Played {value}`) and `interactions_board_enabled`. Both are optional: a file without them imports as before and leaves your interaction types and the switch as they are. A file with a `people` or `residents` key is refused, because people are never in a setup file. The sample file shows the new keys. Nothing uses them yet: the Interactions board comes in a later build.
