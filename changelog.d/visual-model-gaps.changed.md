**The wording the approved designs show.** A setup file that cannot be imported is now described in plain sentences, such as "Error type 3 has no name." and "Locations 1 and 2 are both called North Site.", instead of the place in the file. A name that is already used is refused with "There is already an error type called “Mute Delay”. Names must be different.", a note template pattern without `{value}` with "The pattern needs {value} where the answer goes", and a finished export names the real file ("cs-bingo-board-setup.ejconfig is ready to send."). A setup file may also give a note template an `icon` ("music", "speech"); a file without one is read as before. The app also now knows the extra text the screens show (the version and entry count of a past log, the day it was shared, the colour name of an error type, the footnote of the edit sheet, a preview of a template, and the failed tap's name), which the screens will use as they are updated. Only run off-screen so far, not yet run on a device.
